# SQL Exploratory Data Analysis (EDA) Project 📊

A SQL-based Exploratory Data Analysis project built as part of my AI Engineer learning journey.

## 🎯 Objective

Use SQL to explore, clean, analyze, and understand a real-world dataset.

The goal is to answer meaningful business questions using SQL and identify patterns, trends, and insights from the data.

* PostgreSQL
